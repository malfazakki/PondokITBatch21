# Sisantren - Sistem Informasi Pesantren
---
Sebuah pesantren modern ingin membangun SISTEM INFORMASI MANAJEMEN PESANTREN.
Sistem ini digunakan untuk mengelola data santri, kamar, ustadz, pelajaran, kelas, dan absensi harian.
Mereka ingin sistem ini berbasis database yang rapi agar ke depan mudah dikembangkan menjadi aplikasi
monitoring wali santri.

---

### Run Locally:
```bash
composer install
php artisan migrate
npm run dev
php artisan serve
```
